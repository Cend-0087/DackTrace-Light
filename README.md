# DarkTrace Light

Open Source Network Anomaly Detection System

## Features
- Real-time packet capture
- Signature-based attack detection (SQLi, XSS, CMD injection)
- ML-based anomaly detection (Isolation Forest)
- Real-time blocking via iptables
